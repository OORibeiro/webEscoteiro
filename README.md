# 455º Grupo Escoteiro Fortaleza de Itaipu — Página de divulgação

Site estático (HTML + CSS + JavaScript puro), sem build. Abra `index.html` ou publique a pasta inteira no Netlify.

- `index.html` — página inicial
- `quem-somos.html` — história, missão, valores e ramos em detalhe
- `css/style.css` — estilos (tokens do Design System: Verde #1A4524, Azul #2980B9, Terracota #D35400, Amarelo #F1C40F, Cinza Neve #F5F5F7, Carvão #1D1D1F; Inter + JetBrains Mono)
- `js/main.js` — menu mobile, abas jovem/adulto, buscador de ramo por idade, perguntas frequentes, animações ao rolar
- `img/` — brasão, fotos otimizadas e padrão topográfico

## Antes de publicar
- Confirmar com a liderança as faixas etárias (6–10, 11–14, 15–17, 18–23) e se o formulário também atende adultos voluntários.
- Confirmar autorização de uso das fotos (há menores).
- Endereço e horários ainda não constam no site; adicionar quando o grupo confirmar.
